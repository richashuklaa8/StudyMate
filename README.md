# 🎓 StudyMate — AI Study Assistant

StudyMate is an AI-powered study assistant that converts PDF study notes into clear, structured, and revision-friendly summaries using Google Gemini AI.

## ✨ Features

- 📄 Upload PDF study notes
- 🤖 AI-powered summarization using Gemini
- 🧠 Structured summaries for easier understanding
- 📝 Key concepts and important points
- 🎯 Exam and revision-focused content
- 💻 Simple and responsive web interface

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **AI:** Google Gemini API
- **PDF Processing:** PyPDF
- **API Communication:** REST

## ⚙️ How It Works

1. Upload a PDF containing study material.
2. StudyMate extracts the text from the PDF.
3. The extracted content is sent to Google Gemini.
4. Gemini generates a structured summary.
5. The summary is displayed on the web interface.
